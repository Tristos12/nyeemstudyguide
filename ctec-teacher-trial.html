Before you begin

This is not live AI assessment. The page contains only invented student responses. It does not call an AI provider, send work to a server or contain official CXC marking. Enter only fictional feedback from an approved test, not students' actual writing, names or identifying details.

Two teachers should independently score the feedback for each sample, discuss differences and decide whether the system is suitable for a supervised pilot. Records are stored only in this browser until exported. A teacher's rating evaluates the feedback system, not the student's work.

Trial progress

A passing score shows only that a teacher found the specific feedback acceptable under this proposed checklist. It does not mean live AI can be switched on. Technical controls and school approval remain required.

Before a student pilot

The school must confirm the protected AI credentials, human verification, request limits, affordability, data policy and consent process. A feedback quality trial using fictional responses must pass teacher review before learner access is considered.
