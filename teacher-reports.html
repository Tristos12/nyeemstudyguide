How reporting works

  1. Students open the Learning Hub using their own name, class and four-digit learner code.
  2. On the homepage, they select Download my report.
  3. A teacher receives the JSON files and imports them above.
  4. Use the table to identify students who need additional practice. Repeat the process when updated reports are needed.

A name and class identify a report in this local table. Importing a newer report with the same name and class replaces the earlier one. No learner code, free-text writing or family information is included in these reports.
